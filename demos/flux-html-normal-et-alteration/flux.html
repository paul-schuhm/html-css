Display

La propriété display de chaque élément permet de calculer sa position et ses dimensions sur la zone de rendu afin de peindre les pixels.

Élément de type display: block;

Un paragraphe est un élément de type block (display: block;)

Élément de type display: inline;

Un élément inline, comme em n'occupe que l'espace nécessaire pour afficher son contenu (ne repousse pas les autres éléments à la ligne suivante). Un hyperlien est également un élément inline

Élément de type display: inline-block;

Une image, par exemple, est de type inline-block. Elle ocuppe uniquement une zone égale à sa taille mais on peut redéfinir ses dimensions.

Un élément inline-block se comporte :

  • comme un élément inline, il n'occupe que l'espace nécessaire (propre à ses dimensions)/ne repousse pas l'élément suivant à la ligne
  • comme un élement block au sens où l'on peut définir ses dimensions hauteur et largeur via les propriétés height et width respectivement.
La propriété display a une valeur par défaut pour chaque élément. Il est possible de la surcharger via la propriété CSS display.

Positionnement

Position static (par défaut)

Par défaut, les éléments sont placés dans le flux normal du document, les uns à la suite des autres, en appliquant leur règles de définies par leur propriétés display. Ils sont positionnés de manière static.

Position relative

C'est le flot (ou flux) naturel du document.

Le positionnement

Position static

Il est possible d'altérer le flot naturel du document et la position de chaque élément.

Par défaut, les éléments lorsqu'ils sont placés suivant le flot naturel ont une position: static

Position relative

Ce paraphraphe est positionné de manière relative (décalé par rapport à sa position d'origine) position: relative;

Position absolute

L'élément est retiré du flux normal et aucun espace n'est créé pour l'élément sur la page. Il est ensuite positionné par rapport à son ancêtre le plus proche qui est positionné s'il y en a un ou par rapport au bloc englobant initial sinon. La position finale de l'élément est déterminée par les valeurs de top, right, bottom et left.

Voir l'élément en position absolute

Ce paragraphe est positionné de manière absolue position: absolute;. Sortie du flux, comme en relatif, mais cette fois il est positionné par rapport à son élément parent (body ici). Attention, pour que cela fonctionne il faut définir le parent comme position: relative; !

Position sticky

La position de la boîte est calculée en fonction du flux normal du document. Ensuite, la boîte est décalée par rapport à son ancêtre de défilement le plus proche et par rapport à son bloc englobant selon les valeurs de top, right, bottom et left. Dans tous les cas, y compris avec les éléments table, cela n'affecte pas la position des autres éléments. Ce paragraphe est positionné de manière sticky (position: sticky;). Sortie du flux, comme en position: relative; ! Scrollez vers le bas pour observer son comportement !
