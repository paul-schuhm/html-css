Démonstration des pseudo-éléments ::after et ::before

Les pseudo-éléments sont des mots-clefs (::before, ::after, ::first-line, ::first-letter, etc.) que l'on peut ajouter à un sélecteur pour mettre en forme une partie du ou des éléments sélectionnés. Ces pseudo-éléments sont très utiles pour injecter, transformer du contenu de manière systématique.

Exemple : appliquer les règles de ponctuation correctes pour une liste

Selon les règles typographiques en usage à l'imprimerie nationale, chaque paragraphe d'une énumération introduite par un deux-points, sauf le dernier, se termine par un point-virgule, quelle que soit sa ponctuation interne. Si l'un de ces paragraphes se subdivise à son tour, chaque paragraphe, sauf le dernier, se termine par une virgule.

Voici une liste où tous les signes de ponctuation sont placés en CSS avec les pseudo-éléments :

  • Premier item
  • Deuxième item
  • Troisième élément qui comprend lui-même :
    • un premier élément
    • un deuxième élément
    • un troisième élément
  • Quatrième item
  • Cinquième item
  • Sixième item qui se subdivise lui-même en :
    • un premier élément
    • un deuxième élément

Pour éviter d'avoir à placer ces signes de ponctuation manuellement et faciliter l'ajout ou le déplacement d'un élément, on peut utiliser le pseudo-élément ::after pour appliquer ces règles.

On peut également utiliser le pseudo élément ::before pour systématiquement placer un contenu (icone, texte, etc.) avant un élément.
